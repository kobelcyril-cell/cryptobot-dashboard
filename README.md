# CryptoBot Dashboard

Statische GitHub-Pages-Ansicht fuer den lokalen CryptoBot. Die Webseite liest
alle sichtbaren Werte aus `dashboard-data.json`; Zugangsdaten und Bot-Konfiguration
gehoeren nicht in dieses Repository.

## Lokal ansehen

```powershell
py -m http.server 8000
```

Danach `http://localhost:8000` im Browser oeffnen.
